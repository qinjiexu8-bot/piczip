# 中文文章测试记录

## 测试环境

- 日期：2026-07-29
- 页面：`http://localhost:3000/zh/compress-image-to-100kb`
- 输入文件：`coastal-town-source.png`
- 输入格式：PNG
- 输入尺寸：1536×1024
- 输入大小：2,976,317 字节

## 设置

- 目标大小：100KB
- 输出格式：Auto
- 初始质量：82
- 最大宽度：2400px

## 结果

- 输出格式：WebP
- 输出尺寸：1536×1024
- 输出大小：101,730 字节
- 减少：2,874,587 字节，约 96.58%
- 页面取整显示：99 KB，-97%
- 是否缩放：否

## 结论边界

PicZip 使用 1024 字节作为 1KB，因此本次 100KB 上限为 102,400 字节，结果低于上限 670 字节。
结果只代表这张测试图片和这组设置。若上传系统使用 100,000 字节作为上限，用户仍需检查下载后的实际文件大小。
