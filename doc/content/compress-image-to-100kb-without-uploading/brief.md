## Distinct purpose

The existing `/compress-image-to-100kb` page is the transactional tool page. This guide explains what settings to change when quality reduction alone cannot reach 100KB, using a reproducible PicZip test. It should not repeat the landing page copy.

## Required experiment

1. Start with a PNG or JPG substantially larger than 100KB.
2. Attempt the target while retaining a relatively large maximum width.
3. Record whether PicZip reaches 100KB.
4. If necessary, reduce maximum width and repeat.
5. Explain whether format, pixel dimensions, or quality was the decisive factor.

## Unique value

The article must publish the source dimensions, exact file sizes, settings, result, and a failed or constrained attempt. The central conclusion must come from that test rather than generic compression advice.
