# Content Brief: Compress a Screenshot Without Blurry Text

Status: Approved

- Primary keyword: `compress screenshot without blurry text`
- Intent: Reduce a screenshot while protecting small interface text
- Audience: Support writers, developers, and people sharing interface screenshots
- Problem: Separate format savings from pixel loss caused by resizing
- Matching tool: `/compress-png`
- Distinct purpose: Screenshot readability and dimensions, not broad PNG compression
- Required evidence: Text-heavy screenshot, full-size PNG/WebP results, one resized comparison, exact bytes and dimensions
- Cannibalization rule: Keep small-text review and screenshot workflow central
