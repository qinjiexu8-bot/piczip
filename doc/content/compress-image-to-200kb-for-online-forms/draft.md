# How to Compress an Image to 200KB for an Online Form

The approved article is implemented at:

`src/app/(en)/guides/compress-image-to-200kb-for-online-forms/page.tsx`

## Editorial decisions

- The first paragraph answers the task before explaining compression.
- The article treats file size as one form requirement among format, dimensions, and aspect ratio.
- Two runs use the same source and settings; only maximum width changes.
- It does not claim the smaller result has universally better quality.
- It recommends the full-size result for scans and the 1200px result for ordinary form photos when allowed.
- Exact bytes and rounded interface values are kept distinct.
- Auto selecting WebP is disclosed, with an explicit warning to choose JPG when required.
