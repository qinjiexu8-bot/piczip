# Content Brief: Reduce Image Size for Email Attachments

Status: Approved

## Keyword map

- Primary keyword: `reduce image size for email attachment`
- Search intent: Informational task completion
- Audience: People sending several photos or screenshots by email
- Problem: Make attachments smaller while keeping them readable and convenient to download
- Matching tool page: `/batch-image-compressor`
- Secondary queries:
  - `compress photos for email`
  - `make image attachment smaller`
  - `reduce multiple image sizes for email`

## Distinct purpose

This guide is about choosing a sensible size for email and compressing several images into one ZIP. It should not promise that every mail provider has the same attachment limit.

## Required experiment

Compress a small batch of mixed images, record total size before and after, export the ZIP, and explain when individual files are preferable to one archive.
