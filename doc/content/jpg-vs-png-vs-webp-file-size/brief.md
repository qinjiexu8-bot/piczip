# Content Brief: JPG vs PNG vs WebP File Size

Status: Approved

- Primary keyword: `jpg vs png vs webp file size`
- Intent: Compare formats before choosing an output
- Audience: Website owners and creators deciding between compatibility, transparency, and delivery size
- Problem: Determine which format is smaller without treating one format as universally best
- Matching tools: `/compress-jpg`, `/compress-png`, `/compress-webp`
- Distinct purpose: A controlled same-image comparison, not another format compressor landing page
- Required evidence: One source, fixed dimensions, fixed quality starting point, exact bytes for all formats
- Cannibalization rule: Keep comparison intent central; do not target `compress jpg`, `compress png`, or `compress webp`
